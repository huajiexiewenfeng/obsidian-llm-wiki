# Safety Rules

- Do not delete user files.
- Do not move user files.
- Do not rewrite original notes unless explicitly requested.
- Do not copy external files into the vault.
- Do not copy API keys, tokens, passwords, AK/SK, cookies, private keys, certificates, RTSP credentials, internal endpoints, production logs, or customer data.
- If a file or directory appears sensitive, record only path, type, risk, and recommendation.
- Prefer metadata-only inventory when the user's intent is unclear.
