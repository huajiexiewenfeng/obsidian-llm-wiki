# Synthesis Rules

## When To Save

Save only when the user asks or confirms.

Good candidates:

- project pages
- SOP pages
- article outlines
- learning roadmaps
- cross-topic synthesis
- recurring checklists

## Where To Save

- project or product knowledge: `projects/`
- repeatable procedure: `sops/`
- stable concept or system: `entities/`
- broad subject area: `topics/`
- source summary or index: `sources/`

## Log Entry

```markdown
## [YYYY-MM-DD] query | 知识库问答沉淀

- 问题：
- 使用页面：
- 输出页面：
- 处理策略：
- 下一步建议：
```

## Safety

Do not save:

- credentials
- private endpoint values
- customer details
- raw production logs
- secrets copied from source files
