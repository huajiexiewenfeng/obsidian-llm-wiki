# Answer Format

Prefer concise answers. Include structure only when helpful.

## Standard Answer

```markdown
## Answer

## Evidence Used

## Gaps

## Suggested Save-Back
```

For small questions, a short paragraph plus references is enough.

## Evidence Rules

- Name wiki pages used.
- Mention when using inference.
- Mention when the wiki does not contain enough evidence.
- Do not quote sensitive values.

## Save-Back Suggestions

Suggest saving when the output is:

- a reusable SOP
- a project handoff
- a recurring troubleshooting path
- a learning roadmap
- a presentation or article outline
- a concept synthesis that connects multiple pages
